# Teaching Preferences

## Learning Style
- Experienced video producer — skip basic video concepts, focus on AI-specific workflows
- Engineer — appreciates understanding how things work under the hood
- Learns by doing — prefers hands-on experiments over pure theory

## Lesson Preferences
- Practical and actionable — each lesson should move toward publishing a real video
- Include tool comparisons where relevant
- Balance between "just use it" pragmatism and "here's how it works" depth

## Topics to Avoid
- Basic video production fundamentals (camera work, lighting, composition — already known)
- Basic AI concepts ("what is machine learning" level — already understood)

## Topics to Prioritize
- AI tools mapped to each production stage
- Building a repeatable workflow
- Getting the first video out fast

## Format Preferences
- Concise lessons with clear tool recommendations
- Include links to verify claims independently
